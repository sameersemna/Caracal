## Voiceprint calibration

Skipped: speaker embeddings are not exposed over the REST API. The report exposes only a label's similarity to an *enrolled* speaker (`voiceprint_similarity`), which cannot produce the same/different pairs a threshold calibration needs. `scripts/eval/metrics.py` implements `roc()` and `best_threshold()` and is unit-tested; wire them to an embedding export when one exists.

## Notes

- Cases are submitted through the public REST API to a running server, so the numbers include ingest, ASR, diarization, identity, verification and report assembly.
- WER uses YouTube *manual* captions downloaded with yt-dlp into a temporary directory and the same normalisation as `caption_agreement`; DER uses the reference turns known from the splice construction and a 0.25 s collar around reference boundaries.
- Media and reference files live only in a temporary directory; nothing is written into the repository except this report.
