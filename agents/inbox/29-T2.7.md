## Requirements
1. **`report/assemble.py` — `assemble_report(checkpoints, *, job, settings) -> Report`** (pure; `checkpoints` = dict of stage → checkpoint JSON or
   None). Map every section from its stage: source (ingest + job), audio (normalize; `music_detected` from plan), languages (langid; plan override
   when music), speakers (identity; if identity skipped/failed but align ran → one unnamed `SpeakerIdentity` per label from speaker stats),
   summary/context/chapters/topics/entities/key_quotes/claims (content), verification `[]` and translations `[]` (M3), transcript_ref (counts +
   links), quality (`asr_avg_logprob` = mean segment avg_logprob, `low_confidence_segments` = segments with avg_logprob < −1.0,
   `caption_agreement`, `stages` = {name: status} for **every** stage, `review_flags` = plan + content + identity flags + the deterministic
   docs/04 §11 checks: speaker shares sum ≈ 1 (±0.05), chapters cover ≥ 80 % of duration, caption_agreement < 0.6, > 10 % low-confidence
   segments, any failed stage → `error` flag naming it).
2. **Citations in prose** (verdict 26): for every prose string field (summary.*, context.*, chapter title/summary, topic label, claim text,
   speaker description), remove bracketed or parenthesised evidence-id lists (e.g. `"TED Talk [meta:title, meta:channel]"` → `"TED Talk"`)
   using `EVIDENCE_ID_RE`, and add those ids to the item's `evidence`. Never alter quote text.
3. **Evidence**: `build_evidence_index(...)` from the checkpoints/transcript/captions, then `validate_citations(report, index)`; the returned
   report is what gets stored.
4. **Stage `assemble`**: writes `report.json` and `report.md` (`render_markdown`) atomically, `repos.reports.put(job_id, report, "1.0")`,
   output `{sections: {name: count}, dropped_uncited, review_flags: n}`. It never fails the job because a section is missing.
5. **REST** `GET /v1/jobs/{id}/report?format=json|md` (default json; md → `text/markdown; charset=utf-8`); 409 `job_not_ready` until assemble ran;
   404 for unknown/failed-without-report. **MCP `get_report(job_id, sections?: list[str], format="json"|"markdown")`** → structured object
   (`sections` filters top-level Report keys; unknown section name → `invalid_input`; markdown → `{format, content}`). **`analyze_audio`** done-result
   adds `report_summary: ReportSummary` (keep the M1 `summary`). `JobStatus.links.report` points at the report.
6. Parity: report row available; MCP `get_report` (json) == REST report JSON.
