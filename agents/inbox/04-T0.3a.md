## Goal
A job enqueued in Redis is picked up by a worker, runs through every pipeline stage (stubs in M0), is checkpointed
stage by stage, survives a worker crash (another worker reclaims and resumes it), and finishes `done` — with every
Redis key under `REDIS_PREFIX`.

## Requirements

### storage.py
`class JobFiles` built from `(data_dir: Path, job_id: UUID)`; every path derives from the UUID (docs/06 S10). Properties/methods for each
docs/05 §3 path: `root, source_dir, audio_wav, chunks_dir, chunk(i) (000.wav), captions(lang), stage(name) (stages/<name>.json),
transcript_json, transcript_txt, subtitle(lang, ext), report_json, report_md`. `lang` validated `^[a-z]{2,3}(-[A-Za-z]{2,4})?$|^source$`,
`ext ∈ {srt, vtt}`, stage names must be a `Stage` value → else `CaracalError(invalid_input)`. `write_json(path, obj)` and
`write_text(path, s)` are **atomic** (temp file in the same dir + `os.replace`, fsync file); `read_json(path) -> object | None`. `ensure()` creates dirs.

### pipeline/stages.py
- `class Stage(StrEnum)` in this exact order: `ingest normalize chunk transcribe langid diarize align voiceprint plan content identity verify translate subtitles review assemble`.
  `CRITICAL_STAGES = frozenset({ingest, normalize, transcribe})`.
- `class JobOptions(BaseModel)` (pydantic, `extra="forbid"`) with exactly the fields/defaults of docs/03 §2 `JobCreate.options`
  (`language="auto"`, `target_langs: list[str] | None = None`, `depth: Literal["quick","standard","deep"]="standard"`,
  `diarize`/`verify: Literal["auto","on","off"]="auto"`, `speaker_hints: list[str] = []` (max 20 items × 200 chars), `context_hint: str | None` (≤ 2000 chars)).
- `@dataclass StageContext`: `job_id, options: JobOptions, files: JobFiles, settings, repos (JobRepo…), load: Callable[[Stage], Awaitable[dict | None]], progress: Callable[[float, str], Awaitable[None]]`.
  Later cards add client fields; keep it a plain dataclass.
- `@dataclass(frozen=True) StageResult(status: Literal["done","skipped"], reason: str | None = None, output: dict = {})` (use `field(default_factory=dict)`).
- `StageFn = Callable[[StageContext], Awaitable[StageResult]]`; `default_registry() -> dict[Stage, StageFn]`: every stage → a stub that returns
  `StageResult("skipped", reason="not implemented in M0")`.

### pipeline/runner.py — `async def run_pipeline(job_id, deps: RunnerDeps, registry: Mapping[Stage, StageFn] | None = None) -> str`
`RunnerDeps` dataclass: `settings, repos, queue_events (publisher), cancel_check: Callable[[UUID], Awaitable[bool]], sleep: Callable[[float], Awaitable[None]] = asyncio.sleep`.
Algorithm (docs/01 §4):
1. Load the job; missing → `CaracalError(not_found)`; already terminal → return its status without doing anything.
2. `set_status(running)` (if queued); publish `{"type":"status","status":"running"}`.
3. For each `Stage` in order: if cancelled → `set_status(cancelled)`, publish end event, return. If the checkpoint file exists **and** the stage
   row is `done|skipped` → skip it (resume). Else `upsert_stage(running)`, publish `{"type":"stage","stage","status":"running"}`, call the fn:
   - `CaracalError(retryable=True)` → retry up to **2** more times with `sleep(2)`, `sleep(8)`.
   - success → `files.write_json(files.stage(name), {"status","reason","output"})` **then** `upsert_stage(status, reason)` → publish.
   - failure (non-retryable, retries exhausted, or any other exception) → `upsert_stage(failed, reason=<code: message>)`, publish; if the stage is
     critical → `set_status(failed, error={"code","message","stage"})`, publish end, return `"failed"`; else continue.
4. Whole run inside `asyncio.timeout(settings.CARACAL_JOB_TIMEOUT_S)` → on timeout: `failed` with `internal` / "job timeout".
5. `set_status(done)`; publish end event `{"type":"end","status":"done"}`. Every event also has `"ts"` (ISO-8601 UTC) and `"pct"` (stages finished / total × 100, 1 decimal).
6. `progress(pct, msg)` given to stages calls `repos.jobs.set_progress` and publishes `{"type":"progress",...}`.
Never log transcript/output content at INFO.

### queue.py (docs/05 §2 — the authority)
- `class Keys(prefix: str)`: `key(*parts) -> str` (= prefix + ":".join(parts); each part non-empty, no `*?[]` and no whitespace → `ValueError`),
  plus helpers `jobs_stream, worker(worker_id), lock_whisper, lock_retention, events(job_id), cancel(job_id), search(provider, qhash), ratelimit(h)`.
- `class JobQueue(redis, keys, group="workers")`: `ensure_group()` (MKSTREAM, ignore BUSYGROUP); `enqueue(job_id, kind) -> entry_id`
  (`XADD … MAXLEN ~ 10000`, fields `job_id, kind, enqueued_at`); `read(consumer, *, count, block_ms) -> list[Delivery]`;
  `touch(consumer, entry_id)` (XCLAIM min-idle 0 JUSTID = heartbeat); `ack(entry_id)` (XACK + XDEL);
  `reclaim(consumer, *, min_idle_ms) -> list[Delivery]` (XAUTOCLAIM, with `times_delivered` from XPENDING). `Delivery(entry_id, job_id, kind, times_delivered)`.
- `whisper_lock(redis, keys, *, ttl_ms=960_000, renew_every_s=60, acquire_timeout_s=None)` — async context manager: `SET NX PX` with a random
  owner token, background renew via Lua compare-and-`PEXPIRE`, release via Lua compare-and-`DEL` (never deletes someone else's lock). Generic
  helper `redis_lock(redis, key, …)` shared with the retention lock.
- `publish_event(redis, keys, job_id, event: dict)`, `subscribe_events(redis, keys, job_id) -> AsyncIterator[dict]`.
- `set_cancel(redis, keys, job_id)` (TTL 1 day), `is_cancelled(...) -> bool`.
- `rate_limit(redis, keys, ident_hash, *, limit, window_s=60) -> tuple[bool, int]` (allowed, retry_after_s) — INCR + EXPIRE NX.

### worker.py
`class Worker(settings, redis, repos, *, registry=None, worker_id=None, intervals: WorkerIntervals = default)` where `WorkerIntervals`
holds `heartbeat_s=10, touch_s=60, reclaim_s=60, reclaim_min_idle_ms=300_000, block_ms=5000, max_deliveries=3, shutdown_grace_s=30` (injectable for tests).
`worker_id` default `f"{hostname}-{pid}-{4 hex}"`. `async run(stop: asyncio.Event)`:
- `ensure_group`; heartbeat key `SET … EX 30` every `heartbeat_s`.
- read loop: keep ≤ `CARACAL_WORKER_CONCURRENCY` jobs in flight; each job task runs `run_pipeline` while a side task `touch`es its entry every `touch_s`; on return → `ack`.
- reclaim loop every `reclaim_s`: `reclaim(min_idle_ms)`; delivery with `times_delivered > max_deliveries` → if job not terminal `set_status(failed, error={"code":"internal","message":"worker crashed repeatedly"})`, ack; else run it (resume).
- shutdown on `stop`: stop reading, wait ≤ `shutdown_grace_s` for in-flight jobs; jobs still running are **not** acked (another worker will reclaim).
- `cli worker`: builds real redis (`redis.asyncio.from_url`), engine, Postgres repos, `Worker`; SIGINT/SIGTERM set `stop`; returns 0.
- (Retention task is T4.1 — not in this card.)

## Accept
- **Prefix proof** (`test_queue.py`, `test_worker.py`): with `REDIS_PREFIX="t3st:"`, run enqueue → worker processes a job end-to-end → cancel flag →
  lock acquire/release → rate limit → events; then `SCAN *` on the fakeredis server shows **only** keys starting with `t3st:`, and every published
  channel (record them via a wrapper or `PUBSUB CHANNELS` while subscribed) starts with `t3st:`.
- runner: order of stages; checkpoint written before `upsert_stage(done)`; resume skips done stages and does **not** call their fn again; retry count
  and sleeps `[2, 8]` (inject `sleep`); critical failure → job failed and later stages not run; non-critical failure → continues and job `done`;
  cancel between stages → `cancelled`; timeout → failed; terminal job → no-op; event sequence asserted exactly for a 3-stage scripted registry.
- worker: end-to-end with fakeredis + fake repos → job `done` and stream entry deleted; **crash recovery**: consumer A reads an entry and "dies"
  (never acks), worker B with `reclaim_min_idle_ms=50` reclaims and finishes it, resuming from A's checkpoints; `max_deliveries` exceeded → `failed`
  "worker crashed repeatedly"; concurrency limit respected (with a slow scripted stage, at most N in flight).
- whisper lock: second acquirer waits/times out; a lock whose token was replaced is **not** deleted by the old owner's release; renew extends TTL.
- `Keys.key` rejects `*`, `?`, `[`, whitespace and empty parts.
- `tests/live/test_queue_live.py` (`live`, judge runs it): real Redis with prefix `caracal_t_<8 hex>:` — enqueue/read/ack, lock, events; in `finally`
  delete all keys matching **that** prefix via SCAN and assert none remain. Never touches keys outside its prefix.
- gate green; no real network in the gate.
