## Requirements
1. **`speakers/diarize.py`** — `class Diarizer(settings)`: `available() -> bool` (pyannote + torch importable, `HF_TOKEN` set);
   `async run(wav: Path) -> DiarizationResult` — loads the pipeline once (lazy, guarded by an `asyncio.Lock`), runs in `asyncio.to_thread`,
   device `DIARIZATION_DEVICE` with fallback to CPU if CUDA is unavailable (log once). `DiarizationResult(turns: list[Turn(start, end, label)],
   exclusive_turns: list[Turn], embeddings: dict[label, list[float]] (256 floats, L2-normalised), num_speakers)`. Labels renamed `S1..Sn` by
   **first appearance** (consistently across turns, exclusive turns and embeddings). Pass `num_speakers` only when a caller hint is given.
   Turn times rounded to 3 decimals. Never log transcript text.
2. **`speakers/align.py`** — `assign_speakers(transcript, exclusive_turns) -> Transcript`: each word gets the speaker of the exclusive turn
   overlapping its midpoint; a word in no turn gets the nearest turn's speaker if within 1.0 s, else `None`. Segments are **split at speaker
   changes** (text rebuilt with `join_words`, ids renumbered, `speaker` set when all words agree). `speaker_stats(transcript) -> dict[label,
   {talk_time_s, share, first_seen_s, words}]`.
3. **Intro re-timing** (verdict 15: whisper without DTW places the first words of the TED talk at 0.18 s; speech starts at 13.2 s):
   `retime_outside_speech(transcript, turns, *, max_shift_s=30.0) -> Transcript` — words whose midpoint lies **before the first turn** or in a
   **gap > 2 s between turns** are moved into the following turn: spread evenly from that turn's start up to the first word already inside it,
   order preserved, durations ≥ 0.05 s; never move a word more than `max_shift_s`; segment `start/end` recomputed. Run it inside `align` before
   `assign_speakers`, and record `retimed_words` in the align output.
4. **Stages**: `diarize` → skipped with reason `"unavailable"` when `not diarizer.available()` or `options.diarize == "off"`; otherwise run and
   checkpoint `{num_speakers, turns, exclusive_turns, embeddings}`. `align` → load transcript + diarize checkpoint, retime + assign, rewrite
   `transcript.json`/`.txt` (txt lines become `[mm:ss] S1: text`), `repos.segments.replace_for_job` (with speaker), regenerate the source
   subtitles with speakers (re-run the `subtitles` logic or move subtitles after align — subtitles must reflect speakers and retimed words),
   output `{speakers: speaker_stats, retimed_words}`. Diarize failure → stage `failed`, pipeline continues (non-critical), transcript keeps `speaker=None`.
