## Requirements

### Models (`asr/__init__.py` or `whisper.py`; pydantic or frozen dataclasses, JSON-serialisable via `to_dict()`)
`Word(text, start, end, prob, speaker: str | None = None)`, `Segment(id, start, end, text, words, avg_logprob, no_speech_prob, lang: str | None, speaker: str | None = None)`,
`WhisperResult(language_code, language_prob, language_probs: dict[str, float], duration, segments)`, `Transcript(segments, language_code,
dropped: dict[str, int])`, `LangSpan(code, start, end, confidence)`. Text is stored **stripped**; word text stripped too.

### `whisper.py` — `class WhisperClient(base_url, http: httpx.AsyncClient, *, timeout_s, lock: Callable[[], AbstractAsyncContextManager[None]] | None = None)`
`async transcribe(wav: Path, *, language: str = "auto", translate: bool = False, temperature: float = 0.0) -> WhisperResult`:
- validate `language` (`auto` or `^[a-z]{2,3}$`); the request is made **inside** `lock()` when given (the stage passes `whisper_lock`).
- `language_code` = argmax of `language_probabilities` (fallback: map `detected_language` full name → ISO code with a complete
  whisper name→code table; unknown → `None`); `language_prob` = `detected_language_probability`.
- Errors: connect error / timeout / 5xx → `CaracalError(dependency_down, retryable=True)`; 4xx → `internal`; invalid JSON or missing
  `segments` → `internal`. Never log the transcript text at INFO.
- `async health() -> bool` (`GET /` == 200).

### `merge.py` — `merge_chunks(results: list[WhisperResult], chunks: list[Chunk]) -> Transcript`
1. Shift every segment/word by its chunk's `start_s`.
2. Overlap between chunk *i* and *i+1* is `[chunks[i+1].start_s, chunks[i].end_s]`; cut point `c` = its midpoint. From chunk *i* keep words whose
   midpoint `< c`; from chunk *i+1* keep words whose midpoint `≥ c`. Segments are trimmed to their kept words (text rebuilt from the kept words;
   a segment with no kept words is removed; segments without word timings are kept by their own midpoint).
3. Filters (count each in `dropped`): `no_speech_prob > 0.8 and avg_logprob < -1.0` → `no_speech`; a segment whose normalised text
   (lower-case, punctuation stripped) equals the previous kept segment's for the 3rd+ consecutive time → `repetition`; empty text → `empty`.
4. Renumber `id` from 0 in time order; `segment.lang` = that chunk's `language_code`; `Transcript.language_code` = the code with the most
   speech time (seconds of kept segments).

### `langid.py`
- `language_spans(transcript, *, min_conf=0.5) -> list[LangSpan]` — consecutive segments with the same `lang` form a span; confidence =
  that chunk's `language_prob`; spans whose confidence `< min_conf` get `code="und"`.
- `async refine_spans(transcript, chunk_results, *, recheck: Callable[[float, float], Awaitable[WhisperResult]], max_calls=6) -> Transcript`:
  for chunks with `language_prob < 0.6` and duration > 60 s, re-detect 30 s windows via `recheck(start, end)` (the stage will cut + call whisper)
  and relabel the segments inside each window with the window's language when its prob ≥ 0.6. At most `max_calls` calls in total.
- `languages_summary(transcript) -> list[dict]` → docs/03 §5 `languages` items: `code, name (English name), share (by speech seconds,
  sums to 1), spans [{start,end}], confidence`.

### `captions.py`
- `parse_vtt(text) -> list[CaptionWord(text, start, end)]`: if **any** cue has inline `<hh:mm:ss.mmm>` tags, use **only** tagged cues
  (word times from the tags; first word at the cue start; each word ends where the next starts; last at cue end) and ignore the rolling
  duplicates; otherwise (manual) split each cue's text (all lines, tags like `<i>` removed, entities unescaped) into words spread evenly over the
  cue. Ignore `NOTE`/`STYLE`/`REGION` blocks and cue settings (`align:start position:0%`).
- `caption_agreement(transcript, words, *, window_s=60) -> float | None`: normalise both sides (NFKC, lower-case, strip punctuation incl. `♪`,
  `[Music]`-style bracket tags removed); restrict to the overlapping time range; compute word-level edit distance **per `window_s` window**
  (bucket words by midpoint) so cost stays O(n·w) — never one global O(n·m) matrix; agreement = `1 − Σerrors / Σreference_words` clamped to
  [0, 1], reference = caption words. `None` if either side has < 20 words in the overlap.
