## Requirements — stages (`pipeline/stages.py`)
`StageContext` gains: `whisper: WhisperClient`, `resolver: Resolver`, `redis`, `keys: Keys`, `cancelled: Callable[[], Awaitable[bool]]`.
The worker builds them once per process (one `httpx.AsyncClient`; `WhisperClient(settings.WHISPER_URL, http, timeout_s=…, lock=lambda:
whisper_lock(redis, keys))`). Stage outputs are JSON (paths stored **relative to the job root**). Never log transcript text at INFO.

| Stage | Does | Output (checkpoint) |
|---|---|---|
| `ingest` | `upload` → hard-link (fallback copy) the upload file into `files.source_dir`; `direct` → `download_direct`; `platform` → `ytdlp.fetch_metadata` + `download_audio` + `fetch_platform_captions` (caption failure is logged and ignored). `repos.jobs.set_title(meta.title or filename)` | `{source_kind, url, final_url, filename, size_bytes, sha256, platform: <PlatformMetadata as dict> \| null, captions: [{lang, kind, path}]}` |
| `normalize` | `ffmpeg.normalize(source → files.audio_wav, max_duration_s)` + `ffmpeg.analyse`; delete `source/` afterwards unless `CARACAL_KEEP_MEDIA` | `{probe: {...}, stats: {duration_s, speech_ratio, loudness_lufs, quality, silences}}` |
| `chunk` | `plan_chunks` + `ffmpeg.cut` into `files.chunk(i)` | `{chunks: [{index, start_s, end_s, path}]}` |
| `transcribe` | per chunk: check `cancelled()` → `whisper.transcribe(chunk, language=options.language)`, `progress()`; `merge_chunks`; write `transcript.json` (`Transcript.to_dict()`) and `transcript.txt` (one line per segment, `[mm:ss] text`); `repos.segments.replace_for_job`; delete `chunks/` | `{segments, words, language_code, dropped, chunk_langs: [{start_s, code, prob}]}` |
| `langid` | `refine_spans` (recheck = cut a 30 s window + transcribe, ≤ 6 calls), `languages_summary`; caption agreement if a platform caption file exists; rewrite `transcript.json` if relabelled | `{languages: [...], caption_agreement: float \| null, caption_lang}` |
| `subtitles` | `cues_from_transcript` → `files.subtitle("source","srt"\|"vtt")` (translations come in M3) | `{cues, files: {"source.srt": path, "source.vtt": path}}` |
| all others | unchanged stubs (`skipped`, "not implemented in M1") | — |

If speech_ratio < 0.05 (`normalize` output), `transcribe` still runs (whisper returns ~nothing) — the planner arrives in M2.

## Requirements — REST (docs/03 §2)
- `GET /v1/jobs/{id}/transcript?format=json|txt` (default json) — reads `transcript.json` / `.txt`; missing → job terminal-and-failed →
  404 `not_found`, otherwise 409 `job_not_ready`. JSON = `Transcript.to_dict()` + `{"job_id", "languages"}` from the langid checkpoint.
- `GET /v1/jobs/{id}/subtitles/{lang}.{ext}` — `lang` validated (S10), `ext ∈ {srt, vtt}`; `Content-Type` `application/x-subrip` /
  `text/vtt; charset=utf-8`; `Content-Disposition: attachment; filename="<job_id>.<lang>.<ext>"`; same 404/409 rules.
- `JobStatus.links.subtitles` lists the files that exist (`{"source.srt": url, "source.vtt": url}`).
