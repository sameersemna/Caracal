## Requirements
1. **Units**: from the source cues (after align, so speakers are known): consecutive cues of the same speaker until a cue ends with sentence
   punctuation (`. ? ! … 。 ！ ？ ؟`), max 4 cues / 200 chars per unit.
2. **Translate** (`translate_units(units, target_lang, *, glossary, summary, llm) -> list[str]`): batches of ≈ 25 units, json mode, model
   `{cues: [{i, text}]}` (**not** `items` — reserved); system prompt names the target language in English + native name, keeps glossary names
   verbatim, keeps numbers/units, subtitle register, no added commentary. Validate the exact index set; on mismatch retry the batch once, then
   per-unit calls; a unit that still fails keeps the source text and is counted in `failed_units`. Batches run concurrently (client semaphore).
3. **Redistribute** each translated unit across its source cues: split at word boundaries (CJK: characters) proportionally to the source cues'
   character counts (≥ 1 word per cue), keep each cue's original start/end, wrap ≤ 42 chars × 2 lines (a longer cue may use 3 lines only if
   wrapping cannot fit — count those in `overlong_cues`). RTL languages (ar, he, fa, ur): no extra marks; text kept as the model returned it.
4. **Which languages**: job option `target_langs` (`null` → `CARACAL_DEFAULT_TARGET_LANGS` minus the source language; `[]` → none); ISO
   639-1 codes validated (`^[a-z]{2,3}$`), unknown codes → `invalid_input` at job creation. Planner rule unchanged (skip when nothing to do).
5. **Outputs**: `subtitles/<lang>.srt|vtt`; translate checkpoint `{langs: {lang: {units, failed_units, overlong_cues, duration_s}}}`; report
   `translations: [{lang, status: done|failed, links: {srt, vtt}}]`; `JobStatus.links.subtitles` includes them.
6. **On-demand**: `POST /v1/jobs/{id}/translate {"target_langs": [...]}` (job must be `done`, else 409) → enqueue kind `translate` → worker
   re-runs only translate + subtitles + assemble for those languages (existing languages untouched; re-translating a language overwrites it);
   MCP `translate_job(job_id, target_langs)` → same service method; parity row available.
