1. **pyproject.toml**: `name = "caracal"`, `requires-python = ">=3.12,<3.13"`, src layout (`src/caracal`), hatchling
   build backend, `[project.scripts] caracal = "caracal.cli:main"`.

   markers `live: needs real services (never run by the gate)`, `addopts = "-m 'not live'"`.
2. **config.py**: `Settings(BaseSettings)` with **every** variable in docs/02, exact names, types, defaults.
   Required: `CARACAL_API_TOKEN` (SecretStr, ≥ 32 chars → validation error otherwise), `DATABASE_URL`, `REDIS_URL`.
   CSV vars (`SEARCH_PROVIDERS`, `CARACAL_DEFAULT_TARGET_LANGS`) parse into `list[str]` (strip, lowercase, drop empty).
   Optional secrets (`HF_TOKEN`, `BRAVE_API_KEY`, `EXA_API_KEY`) become `None` when unset **or empty string**.
   `get_settings()` cached accessor. `env_file=".env"`, `extra="ignore"`.
   Validators (docs/02): Ollama URL normalisation; `DATABASE_URL` scheme normalisation to `postgresql+asyncpg://`
   (keep user, password, host, port, db and query intact); `REDIS_PREFIX` non-empty, `:` appended if missing.
3. **log.py**: `get_logger(name)` → stdlib logger writing **JSON lines to stderr** (`ts, level, logger, msg`, plus
   `extra` fields). `redact(value: str) -> str` masks: bearer tokens (`Bearer xxx` → `Bearer ***`), `api_key=`/
   `token=`/`key=` query or kv values, DSN passwords (`scheme://user:secret@host` → `scheme://user:***@host`).
   The JSON formatter applies `redact` to the message and every string extra. `configure_logging(level)`.
4. **errors.py**: `class ErrorCode(StrEnum)` with exactly the codes in docs/03 §4; `HTTP_STATUS: dict[ErrorCode,int]`
   per the table; `class CaracalError(Exception)` with `code`, `message`, `details: dict[str, object]`,
   `retryable: bool = False`, and `to_dict()` → `{"error": {"code","message","details"}}`.
5. **cli.py**: `main(argv: list[str] | None = None) -> int` using argparse with subcommands
   `serve | worker | mcp-stdio | migrate | doctor`. In this card every subcommand except `doctor` writes
   `"<name>: available from a later milestone"` to **stderr** and returns 2. `doctor` loads Settings and reports
   (to stderr, as JSON lines via the logger) whether config is valid, then returns 0/1. No network calls yet.
6. **scripts/gate.sh**: exactly the steps in docs/07 §1, `set -euo pipefail`, prints a clear `GATE: PASS` / fails fast.
7. **scripts/check_rules.py**: implements every rule in docs/07 §2 **except** the "module not listed in docs/01 §3"
   rule — implement that one too by parsing the code block in `docs/01-architecture.md` §3 (lines under
   `src/caracal/`), treating `dir/**`, a trailing-slash directory entry such as `migrations/` (= everything below it),
   `{a,b}` brace lists and `prompts/*.md` patterns correctly. `__init__.py` is always allowed in a directory that has
   at least one listed module. Only `.py` files are checked. A layout line may list several paths separated by
   whitespace (e.g. `search/brave.py  search/exa.py  search/router.py (...)`); a token is a path if it ends in `.py`,
   ends in `/`, or contains `*` — everything else on the line is description. Usage:
   `python scripts/check_rules.py [root]` (default `src/caracal`), prints `path:line: rule: excerpt` per hit,
   exits 1 on any hit. It must not flag itself or tests (it scans only the given root).
8. `.env.example`: every docs/02 variable, defaults filled in, secrets as `change-me` placeholders.
   `.gitignore` already exists (owner's, contains `.env`) — keep its lines and append: `.venv/`, `data/`, `agents/logs/`, `__pycache__/`, `.mypy_cache/`, `.ruff_cache/`, `.pytest_cache/`.
