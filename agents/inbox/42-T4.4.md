## Requirements
1. **`word_groups(words) -> list[WordGroup]`** in `asr/__init__.py`: consecutive tokens are one group while the next token has
   `space_before == False` (this also attaches pure punctuation such as `,` `.` `."` to the preceding word). `WordGroup(text (join_words of its
   tokens), start (first token), end (last token), tokens: tuple[int, int] (global index span), speaker (majority of its tokens' speakers, ties →
   first token's), space_before (first token's))`. The first token of a transcript always starts a group.
2. **Segmenter**: build cues from groups — cue breaks and line breaks happen **only between groups**; the char limit is measured on group text;
   a single group longer than `max_chars` stays whole on its own line (as single long words do today). `Cue.word_span` keeps **token** indices
   (translation/redistribution relies on it) — the span covers whole groups.
3. **Caption agreement**: tokenise the transcript side by word groups (`group.text`), not tokens, before normalisation.
4. **Align**: `assign_speakers` assigns one speaker per **group** (by the group's midpoint) and writes it to every token of the group, so a word is
   never split between speakers; segments still split at speaker changes.
5. **`canonical_url(url) -> str`** in `ingest/router.py` (pure, no network): lower-case scheme/host, drop fragment and tracking params (`utm_*`,
   `si`, `fbclid`, `gclid`, `feature`, `t`, `start`); YouTube family (`youtube.com`, `www.`, `m.`, `music.` and `youtu.be`) with a valid 11-char id
   from `watch?v=`, `youtu.be/<id>`, `/shorts/`, `/embed/`, `/live/`, `/v/` → `https://www.youtube.com/watch?v=<id>`; anything else → the cleaned URL.
   `create_job` stores the **canonical** URL as `source_url` and uses it for the dedup lookup; it also tries the raw URL for rows created before
   this change. Uploads unchanged (sha256).
