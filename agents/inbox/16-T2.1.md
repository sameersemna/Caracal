## Requirements
1. **`llm/schema.py`**: `prepare_schema(model_cls) -> dict` (cached): inline `$ref`/`$defs` recursively (cycles → `ValueError`), drop `title`,
   append `" Must be exactly one of: a, b, c."` to every enum's description. `coerce(value, schema, *, synonyms: Mapping[str, str]) -> object`
   implementing docs/04 §1 step 2 (enum case/synonyms, numeric strings, `"null"`/`""` → None for nullable, scalar → list, clamp to
   minimum/maximum, unknown extra keys left for pydantic to reject or ignore per the model's config). `DEFAULT_SYNONYMS` covers at least
   location/loc/gpe/city/country→place, organization/organisation/company/institution→org, per/people/human→person, time/year→date.
2. **`llm/jsonx.py`**: `extract_json(text) -> dict` — strip ```json fences, find the outermost balanced `{…}` (string-aware), parse; else
   `CaracalError(internal)`.
3. **`llm/client.py`** — `LLMClient(settings, http, *, sleep=asyncio.sleep, semaphore=None)`:
   - `async call_tool(*, prompt, system, model_cls, tool_name, tool_description, temperature=0.1, max_tokens=4096, synonyms=None) -> ToolResult[T]`
     where `ToolResult(value: T, meta: CallMeta(model, endpoint: "cloud"|"local", attempts, coerced, fallback_used, duration_s))`.
   - `async chat(*, prompt, system, temperature=0.3, max_tokens=2048) -> str`.
   - Endpoint selection, request body (`stream:false`, `keep_alive`, `options:{temperature, num_predict}`, `tools`), retries (1 s, 4 s on
     transport/5xx/timeout), fallback after 2 consecutive primary failures **or** immediately on 401/403 (log `llm.auth_failed` once per process),
     repair loop (max 2) exactly per docs/04 §1. The system prompt always ends with
     `You MUST answer by calling the tool <tool_name> exactly once. Use the exact field names and allowed values from the tool schema.`
   - Concurrency: `asyncio.Semaphore(CARACAL_LLM_CONCURRENCY)` shared per client. Timeout `LLM_TIMEOUT_S` per request.
   - Logging: INFO = model, endpoint, attempts, coerced, duration (never prompt/args text); DEBUG may include ≤ 500 chars, redacted.
4. **Prompt loader** (`llm/prompts/__init__.py`): `load_prompt(name, **vars) -> str` reads `<name>.md` from the package, substitutes
   `{placeholders}` (missing var → `KeyError`; braces inside DATA must not be interpreted — substitute with `str.replace` on known keys, not `format`),
   and prepends `_guard.md`. `wrap_data(label, text) -> str` produces
   `<<<DATA:{label}>>>\n{text}\n<<<END:{label}>>>` after removing any occurrence of `<<<` / `>>>` from `text` (S9: data cannot close the block).
