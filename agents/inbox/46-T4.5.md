## Requirements
1. **Model references**: `cloud:<name>` → `OLLAMA_CLOUD_URL` with the bearer key (error at startup if the key is missing); `local:<name>` →
   `OLLAMA_LOCAL_URL`; a bare `<name>` → `OLLAMA_LOCAL_URL` (the daemon proxies `-cloud` / `:cloud` tags to ollama.com). Parsed into
   `ModelRef(endpoint, name, raw)`.
2. **Config**: `LLM_ALLOWED_MODELS` (csv of refs) and routes `LLM_ROUTE_DEFAULT`, `LLM_ROUTE_PLAN`, `LLM_ROUTE_CONTENT`, `LLM_ROUTE_IDENTITY`,
   `LLM_ROUTE_VERIFY`, `LLM_ROUTE_TRANSLATE`, `LLM_ROUTE_REVIEW`, `LLM_ROUTE_QA` (csv chains, first = preferred). A missing task route uses
   DEFAULT. **Validation at startup**: every ref in every route must be in `LLM_ALLOWED_MODELS` (compare normalised refs) → otherwise a clear
   `ValidationError` naming the route and model. **Backward compatibility**: when no `LLM_ROUTE_*` and no `LLM_ALLOWED_MODELS` are set, the
   chain is derived exactly as today (`cloud:LLM_MODEL` if a cloud key exists else `LLM_LOCAL_PROXY_MODEL`, then `local:LLM_FALLBACK_MODEL`) and
   the allow-list is that chain — existing deployments keep working unchanged.
3. **Client**: `call_tool(..., route: Route)` / `chat(..., route=…)` (`Route` = StrEnum of the seven tasks + default). Per call: try each ref of the
   route's chain in order; per ref the existing transport retries apply; **move to the next ref** on: 2 consecutive transport/5xx/timeout failures,
   auth 401/403 (log `llm.auth_failed` once per ref), 404 model-not-found, or invalid output after the repair attempts. Timeouts: `LLM_TIMEOUT_S`
   for the first ref, `max(LLM_TIMEOUT_S, 240)` for local refs (cold start). `CallMeta` gains `route` and `model_ref` (the ref that answered) and
   `refs_tried`. Metrics: `caracal_llm_calls_total{route,model,endpoint,mode,fallback}`. Never log prompts.
4. **Call sites**: planner → PLAN; content (all calls) → CONTENT; identity (mentions) → IDENTITY; verify (queries, judge, identity-web) → VERIFY;
   translate → TRANSLATE; review → REVIEW; qa (answer + keywords) → QA.
5. **Doctor**: one line per allowed model: `POST /api/show` on its endpoint (cloud: with bearer) → ok/fail (+ the routes that use it); a route whose
   **every** model fails → required check fails; a route with a failing fallback only → warn.
6. **Docs for the owner**: `.env.example` and README show the owner's configuration and the reference syntax:
   ```
   LLM_ALLOWED_MODELS=gemma4:31b-cloud,local:gemma4:31b
   LLM_ROUTE_DEFAULT=gemma4:31b-cloud,local:gemma4:31b
   # optional per task, e.g. LLM_ROUTE_QA=gemma4:31b-cloud
   ```
