## Requirements

### Process runner (in `ffmpeg.py`, private)
`_run(argv: list[str], *, timeout_s: float) -> tuple[bytes, bytes]` using `asyncio.create_subprocess_exec` (argv list, `stdin=DEVNULL`), kill
the process (and await it) on timeout or cancellation → `CaracalError(internal, "ffmpeg timed out", retryable=False)`. Non-zero exit → the
caller maps it. Keep at most the last 4 KiB of stderr, and never put file paths outside the job dir or the full stderr into error messages.
Binary names `ffmpeg`/`ffprobe` from `shutil.which` at call time (missing → `dependency_down`). Every argv starts with
`-hide_banner -nostdin` (ffmpeg) / `-hide_banner` (ffprobe) and `-v error` and **includes both whitelists before `-i`** for user media.

### `async def probe(path: Path) -> ProbeInfo`
`ffprobe -v error -protocol_whitelist file -format_whitelist ALLOWED -print_format json -show_format -show_streams <path>`.
`ProbeInfo(format_name, duration_s: float | None, bit_rate, audio_streams: int, video_streams: int, codec: str | None, sample_rate: int | None,
channels: int | None, tags: dict[str, str])` — first audio stream; `tags` from format tags, lower-cased keys, keep only
`title, artist, album, album_artist, date, comment, language, genre, encoder, creation_time, composer, publisher`, values ≤ 500 chars.
Errors: whitelist rejection / "Invalid data" / no streams → `unsupported_media`; `audio_streams == 0` → `unsupported_media` ("no audio stream").

### `async def normalize(src: Path, dst: Path, *, max_duration_s: float) -> ProbeInfo`
Probe first; duration > max → `too_large` (before converting). Then
`ffmpeg -hide_banner -nostdin -v error -protocol_whitelist file -format_whitelist ALLOWED -i <src> -map 0:a:0 -vn -sn -dn -ac 1 -ar 16000 -c:a pcm_s16le -f wav <dst>.part`
then `os.replace` to `dst`. Timeout `max(120, 0.5 × duration)`. Partial file removed on any failure. Return the probe of the **source**.

### `async def analyse(wav: Path, *, noise_db=-35, min_silence_s=0.4) -> AudioStats`
One ffmpeg pass on our own WAV: `-af silencedetect=noise={noise_db}dB:d={min_silence_s},ebur128=framelog=quiet -f null -`.
Parse stderr: `silence_start: x` / `silence_end: y` pairs (an unterminated final silence ends at the duration), and the ebur128 summary
`I: -23.4 LUFS`. `AudioStats(duration_s, silences: list[tuple[float, float]], speech_ratio = 1 − Σsilence / duration (clamped 0..1),
loudness_lufs: float | None, quality: "good"|"fair"|"poor")` with quality = poor if `speech_ratio < 0.05 or loudness < -45`, fair if
`loudness < -30`, else good. (`analyse` reads our WAV, but keep the whitelists anyway.) Note: `silencedetect`/`ebur128` log at INFO level,
so this call needs `-v info` (not `-v error`) — parse only the lines you need.

### `async def cut(src: Path, dst: Path, start_s: float, end_s: float) -> None`
`ffmpeg … -ss <start> -to <end> -i <src> -c:a pcm_s16le -ar 16000 -ac 1 <dst>.part` → rename. Validate `0 ≤ start < end`.

### `chunking.plan_chunks(duration_s, silences, *, target_s=600, max_s=900, overlap_s=1.0) -> list[Chunk]` (pure)
`Chunk(index, start_s, end_s)`. `duration ≤ max_s` → one chunk `[0, duration]`. Otherwise walk boundaries: the next boundary is the midpoint
of the silence whose midpoint is closest to `prev + target_s`, chosen among silences with midpoint in `[prev + target_s − 120, prev + max_s]`;
if none, hard cut at `prev + target_s`. Chunk i = `[b_i − overlap_s (0 for i = 0), b_{i+1}]`. The last chunk ends at `duration`; if the
remainder after the last boundary would be < 30 s, merge it into the previous chunk (which may then exceed `target_s` but never `max_s + 30`).
Invariants (test with a property-style loop over random silence sets): starts strictly increase, chunks cover `[0, duration]`, consecutive
overlap == `overlap_s` (except merged tail), every chunk ≤ `max_s + overlap_s + 30`.
