## Requirements
1. **`credit_spans(result, chunk, *, min_s=8.0) -> list[tuple[float, float]]`** (pure, `merge.py`): absolute `(start, end)` of every
   segment of one chunk's raw `WhisperResult` that `is_hallucinated_credit(normalise_text(text))` and lasts **> `min_s`**.
2. **`recovery_windows(start, end, *, size=10.0, overlap=1.0) -> list[tuple[float, float]]`** (pure): starts `s, s+9, …` while
   `start + size < end`, then a final window `[max(s, end − size), end]`; a span ≤ `size` → one window. `(0, 30)` →
   `[(0,10), (9,19), (18,28), (20,30)]` exactly.
3. **`stage_transcribe`**: after a chunk's whisper call, for each credit span (job budget **6** spans, in order), cut each recovery
   window from `ctx.files.audio_wav` (absolute times) into a temp file under the job dir, transcribe it with the same client and
   `language`, delete the temp file. Then merge: the chunk's credit segment is removed and the windows' results take its place, with
   the normal overlap/midpoint rule between windows (build `Chunk`s for the windows; reuse `merge_chunks` machinery — do not write a
   second overlap algorithm) and the normal filters (the `[0,10]` credit is then dropped by the edge rule). Words from a window are
   trimmed to the credit span. Output `dropped.credit_recovered_spans` (int); log `transcribe.credit_recovered` with span and number
   of recovered segments. Cancel check between windows. `_record_whisper_seconds` for each window.
4. **Name rule** (`translate.py` + prompt): replace `_LATIN_NAME_RULE`/`_NON_LATIN_NAME_RULE` by a rule chosen from (source script,
   target script) per docs/04 §10: same script → keep as written; different script → conventional target-language form, else a
   standard romanisation. The source script is detected from the units' text (Han/Kana/Hangul/Thai/Arabic/Hebrew/Cyrillic/Devanagari
   vs Latin). The glossary line must no longer say "kept verbatim" across scripts.
5. **Script-leak check**: for a Latin-script target, a translated unit containing letters of any of those non-Latin scripts makes the
   batch invalid (same path as an index mismatch: retry once, then per-unit). Per-unit: one retry with an extra system line
   ("Write every name in the Latin script.") ; if it still leaks, keep that translation (never the source text, never dropped) and
   count it. `TranslatedUnits` gets `script_leaks: int`; `stage_translate` output gets `"script_leaks"` per language. Non-Latin targets
   are not checked. Digits, punctuation, `°`, `€` etc. are not letters and never count.
