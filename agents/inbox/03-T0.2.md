## Requirements
1. **tables.py** — SQLAlchemy Core `MetaData(schema=None)` + `Table`s exactly per docs/05 §1 (except `voiceprints`):
   `jobs`, `job_stages`, `uploads`, `reports`, `segments`. `segments.tsv` is `TSVECTOR` with
   `Computed("to_tsvector('simple', text)", persisted=True)`; GIN index on it. Indexes as listed. FKs `ON DELETE CASCADE`.
   String enums are `text` + `CHECK` constraints: jobs.status ∈ `queued,running,done,failed,cancelled`;
   job_stages.status ∈ `pending,running,done,skipped,failed`; jobs.source_kind ∈ `upload,direct,platform`.
2. **engine.py** — `make_engine(settings) -> AsyncEngine` (asyncpg; `pool_pre_ping=True`; `connect_args={"server_settings": {"search_path": <schema>}}`).
   `session_scope(engine)` async context manager yielding an `AsyncConnection` inside a transaction.
   No SQL string building with user data — Core expressions / bound parameters only.
3. **repo.py** — `typing.Protocol`s and Postgres implementations (all methods `async`):
   - `JobRepo`: `create(*, source_kind, source_url, upload_id, title, options, sha256) -> JobRecord`; `get(job_id) -> JobRecord | None`;
     `list(*, status=None, limit=20, cursor=None) -> tuple[list[JobRecord], str | None]` (keyset on `(created_at desc, id desc)`,
     opaque url-safe base64 cursor; invalid cursor → `CaracalError(invalid_input)`; limit clamped 1..100);
     `set_status(job_id, status, *, error=None)` (sets `finished_at` for done/failed/cancelled); `set_progress(job_id, progress: dict)`;
     `set_title(job_id, title)`; `upsert_stage(job_id, name, *, status, reason=None)` (increments `attempts` when status becomes
     `running`; sets `started_at` on running, `ended_at` on done/skipped/failed); `list_stages(job_id) -> list[StageRecord]`;
     `find_recent_done(*, sha256=None, source_url=None, options, within_days=7) -> JobRecord | None` (docs/05 §1 dedup); `delete(job_id)`.
   - `UploadRepo`: `create(*, filename, size_bytes, sha256, path) -> UploadRecord`; `get(id)`; `consume(id, job_id)` (fails with
     `invalid_input` if already consumed — atomic `UPDATE … WHERE consumed_by IS NULL`); `list_unconsumed_older_than(hours)`.
   - `ReportRepo`: `put(job_id, report: dict, schema_version)` (upsert); `get(job_id) -> dict | None`.
   - `SegmentRepo`: `replace_for_job(job_id, segments: list[SegmentRow])` (delete + bulk insert in one transaction);
     `search(query, *, limit=20) -> list[SearchHit]` using `websearch_to_tsquery('simple', :q)` and `ts_rank`, joined with `jobs.title`.
   - Records are frozen dataclasses (`JobRecord`, `StageRecord`, `UploadRecord`, `SegmentRow`, `SearchHit`) with exactly the table columns.
   - Unknown ids → `None` from getters; mutating methods on unknown ids → `CaracalError(not_found)`.
   - Status transition guard in `set_status`: terminal states (`done|failed|cancelled`) cannot change → `CaracalError(invalid_input)`.
4. **Fake** (`tests/fakes/repo.py`): in-memory implementations of all four protocols with identical semantics (including cursor,
   transition guard, consume atomicity, search ranking approximated by term-match count — document that the ranking order is the only allowed difference).
5. **Shared suite** (`tests/repo_contract.py`): plain async functions `case_*(repos)` covering every method and every error path above.
   `tests/unit/test_repo_fake.py` runs every case against the fake; `tests/live/test_db.py` (`@pytest.mark.live`) runs every case against
   Postgres in a **throwaway schema** `caracal_t_<8 hex>`: create schema → `alembic upgrade head` (programmatically) → cases → `DROP SCHEMA … CASCADE`
   in a `finally`. The live test reads the real `DATABASE_URL` from Settings (it is run by the judge, not by you).
6. **Migrations**: async alembic `env.py` that takes the URL and schema from `get_settings()` (never from `alembic.ini`), sets
   `version_table_schema=<schema>` and `search_path`; `0001_initial.py` creates the schema objects above (handwritten, not autogenerate
   output pasted blindly) and starts with `CREATE EXTENSION IF NOT EXISTS vector` (needed in T2.3; harmless now). `downgrade()` drops everything it created except the extension.
7. **cli.py** `migrate`: runs `alembic upgrade head` programmatically (`alembic.config.Config` + `command.upgrade`), returns 0/1, logs via `caracal.log`.
8. **test_db_tables.py**: compile the `CREATE TABLE` DDL for the postgresql dialect and assert columns, types, CHECK constraints, the computed
   `tsv` column and that no table is named `voiceprints` and no column is named `start`/`end`.

## Accept
- gate green; every shared case passes on the fake; ≥ 1 case per error path (not_found, invalid_input on bad cursor, terminal-state guard, double consume).
- `alembic upgrade head` + `downgrade base` code paths exist and are exercised by the live test (judge runs it on latitude).
- No network in the gate (the live test is excluded by the `live` marker).
