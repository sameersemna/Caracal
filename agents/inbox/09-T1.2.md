## Requirements — `ingest/ytdlp.py`
1. **Options builder** `build_options(settings, *, dest_dir: Path, cancel: threading.Event, purpose: Literal["metadata","audio","captions"]) -> dict`
   — one place, unit-tested key by key:
   `quiet=True, no_warnings=True, noprogress=True, logger=<_YtdlpLogger adapter to caracal.log (debug→DEBUG, info→DEBUG, warning→WARNING,
   error→WARNING; messages through redact)>, noplaylist=True, allowed_extractors=["default","-generic"], enable_file_urls=False,
   socket_timeout=30, retries=3, fragment_retries=3, restrictfilenames=True, paths={"home": str(dest_dir)},
   outtmpl={"default": "source.%(ext)s"}` (fixed — **no** user-controlled template parts), `max_filesize=CARACAL_MAX_UPLOAD_MB*1MiB`,
   `format="bestaudio/best"`, `postprocessors=[]`, no `exec`/`postprocessor_args`/`external_downloader`, `cookiefile` only if
   `YTDLP_COOKIES_FILE` is set, `match_filter=<callable>` that rejects `is_live`/`was_live is False and live_status in {"is_live","is_upcoming"}`
   and `duration > CARACAL_MAX_DURATION_S` (return a reason string), `progress_hooks=[<hook raising _Cancelled when cancel.is_set()>]`.
   `purpose="metadata"` adds `skip_download=True`; `purpose="captions"` adds `skip_download=True, writesubtitles=True,
   writeautomaticsub=True, subtitlesformat="vtt", subtitleslangs=[<lang>, f"{<lang>}-orig"]`.
2. **SSRF pre-check**: every public function first runs `resolve_and_check(url, resolver=…)` (host-level check; injectable resolver).
3. **Playlists**: if the URL itself is a playlist/channel (`info["_type"] in {"playlist","multi_video"}` from a flat metadata probe, or URL
   has `list=` without `v=`) → `CaracalError(invalid_input, "one item per job")`.
4. `async def fetch_metadata(url, settings, *, resolver) -> PlatformMetadata` (frozen dataclass): `id, title, uploader, channel, channel_url,
   upload_date, duration, description, tags, categories, chapters, language, view_count, webpage_url, extractor` (missing → None / []).
   `description` truncated to 5 000 chars.
5. `async def download_audio(url, files: JobFiles, settings, *, resolver, cancel) -> DownloadedAudio(path, ext, size_bytes, sha256)`:
   downloads into `files.source_dir`; the resulting file is the single `source.*` there (verify exactly one); sha256 computed after.
6. `async def fetch_platform_captions(url, meta: PlatformMetadata, files, settings, *, resolver) -> list[CaptionTrack(lang, kind:"manual"|"auto", path)]`:
   language = `meta.language` or (if None) the first manual subtitle language; prefer **manual** over automatic; for automatic YouTube
   captions take the original-language track (`<lang>-orig` or `<lang>`), never machine-translated tracks. Save as `files.captions(lang)`.
   No captions → `[]` (not an error).
7. All yt-dlp calls run in `asyncio.to_thread` with an overall `asyncio.timeout` (metadata 60 s, captions 60 s, audio `CARACAL_JOB_TIMEOUT_S`);
   on timeout/cancel set the `cancel` event so the progress hook aborts the download, then raise.
8. **Error mapping** (`yt_dlp.utils.DownloadError` / `ExtractorError` messages): private/removed/unavailable/geo/age/"Sign in" →
   `source_unavailable` (message: a short category, never the raw yt-dlp text with URLs); "No suitable extractor" → `source_unavailable`
   ("unsupported site"); match_filter rejection → `too_large` (duration) or `invalid_input` (live); file too large → `too_large`;
   anything else → `source_unavailable` with `retryable=True` for network errors (`timed out`, `Connection`, `HTTP Error 5`).
