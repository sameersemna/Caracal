## Requirements
1. **`caracal doctor [--json] [--deep]`** — one line per check `{check, status: ok|warn|fail, detail}` (never a secret), exit 1 if any **required**
   check fails: config valid · Postgres reachable + pgvector `to_regtype('vector')` visible + alembic at head · Redis reachable + a write/read/delete of
   one `REDIS_PREFIX` key · whisper `GET /` · Ollama cloud (key present → `GET /api/tags` 200) and local `LLM_FALLBACK_MODEL` listed ·
   ffmpeg/ffprobe present + `-format_whitelist` supported · yt-dlp version + node found + `yt_dlp_ejs` importable · pyannote importable + CUDA
   available (warn if not) + `HF_TOKEN` set · Brave/Exa keys present (`--deep`: one real query each) · free disk in `CARACAL_DATA_DIR` (warn < 20 GB).
   Required = config, Postgres, Redis, whisper, Ollama (cloud **or** local), ffmpeg.
2. **Retention** (docs/05 §3): `ops.run_retention(now, *, dry_run)` deletes `audio.wav`, `source/`, `chunks/` of jobs finished more than
   `CARACAL_RETENTION_DAYS` ago (never transcript/subtitles/report/stages), and unconsumed uploads older than 24 h (file + row); paths built only via
   `JobFiles`/`UploadFiles` and must resolve inside `CARACAL_DATA_DIR`. Worker runs it daily under `Keys.lock_retention()`; CLI `caracal retention
   [--dry-run]` prints what it would delete / deleted (counts + bytes).
3. **`GET /metrics`** (bearer-protected like `/v1`): Prometheus text format, no third-party library: `caracal_jobs_total{status}`, `caracal_stage_seconds_
   {sum,count}{stage}`, `caracal_llm_calls_total{endpoint,mode,fallback}`, `caracal_search_queries_total{provider,cached}`, `caracal_search_cost_usd_total`,
   `caracal_whisper_audio_seconds_total`. Counters live in Redis under `REDIS_PREFIX` (`metrics:` hash keys) so API and worker share them.
4. **systemd units** (`deploy/`): `caracal-api.service` (`ExecStart=<repo>/.venv/bin/caracal serve`) and `caracal-worker.service`
   (`… caracal worker`), `User=sameer`, `WorkingDirectory=<repo>`, `EnvironmentFile=<repo>/.env`, `Restart=on-failure`, `RestartSec=5`,
   `NoNewPrivileges=true`, `ProtectSystem=strict`, `ReadWritePaths=<repo>/data`, `PrivateTmp=true`, `ProtectHome=read-only` (repo path still readable),
   worker without `PrivateDevices` (needs the GPU), `TimeoutStopSec=60` (worker graceful shutdown). `deploy/README.md`: install / enable / logs commands
   (the owner runs them with sudo — the worker must not).
5. **`scripts/live-suite.sh`**: the judge harness as a one-command runner — create a throwaway schema + prefix, `caracal migrate`, start `serve` +
   `worker` (by PID, `.venv/bin/caracal` directly — never through `uv run`, which leaves orphans), export the live-test env vars, run `pytest -m live
   tests/live`, then always clean up (kill PIDs, drop schema, delete prefix keys, remove the data dir) via `trap`. Exit code = pytest's.
6. **README.md**: what Caracal does; install (`uv sync --extra speakers`, GPU notes from docs/00); `.env`; `caracal doctor` / `migrate` / `serve` /
   `worker`; REST quick-start with `curl` (upload, create job, events, report, transcript, subtitles, translate, ask, search, speakers); MCP setup for
   HTTP (`http://<host>:11404/mcp/` + `Authorization: Bearer`) and stdio (`caracal mcp-stdio`) with a Claude Code / Claude Desktop config snippet;
   the tool list; privacy (voiceprints are biometric, consent, delete); known limitations (impressionists split into several speakers; whisper word
   timing without DTW; VPN blocks some sites; music-only audio).
