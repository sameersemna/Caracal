## Requirements
1. **`create_app(settings, deps: AppDeps | None = None) -> FastAPI`**. `AppDeps` dataclass: `repos` (jobs, uploads, reports, segments), `redis`,
   `http: httpx.AsyncClient` (for health checks), `keys: Keys`, `queue: JobQueue`. When `deps` is None a lifespan builds the real ones
   (engine + Postgres repos, `redis.asyncio.from_url`, httpx client) and disposes them on shutdown. Tests always inject fakes
   (fake repos from `tests/fakes/repo.py`, `fakeredis.FakeAsyncRedis`, an `httpx.MockTransport` client).
2. **Errors**: exception handlers → docs/03 §1 envelope. `CaracalError` → `HTTP_STATUS[code]`; `RequestValidationError` → 422 `invalid_input`
   with `details.errors` (field locations and messages only — **never echo input values**); any other exception → 500 `internal`, message
   `"internal error"`, logged with traceback at ERROR (never returned to the client). 404 for unknown routes uses the envelope too.
3. **Auth (S1)**: dependency on every `/v1/*` route; missing/malformed/wrong bearer → 401 `unauthorized` + `WWW-Authenticate: Bearer`;
   `hmac.compare_digest` on bytes. `/healthz` is public.
4. **Origin (S2)**: middleware for paths starting with `/mcp`: allow requests with no `Origin`, or an Origin equal to the origin of
   `CARACAL_PUBLIC_BASE_URL`, or `http(s)://localhost[:port]` / `http(s)://127.0.0.1[:port]`; anything else → 403 envelope `unauthorized`.
   (No MCP routes exist yet — test it with a dummy route mounted under `/mcp` in the test app.)
5. **`POST /v1/jobs`** (`JobCreate` in `api/schemas.py`, reusing `JobOptions`; `source` is exactly one of `{url}` / `{upload_id}`, `extra="forbid"`):
   - body > 64 KiB → 413 `too_large`. `url`: http/https only, ≤ 2048 chars, host present → else 422 `invalid_input` (SSRF resolution is T1.1).
   - rate limit (S11): `ident = sha1(token + client_ip)` → `rate_limit(...)`; denied → 429 `rate_limited` + `Retry-After`.
   - `upload_id`: must exist (404 `not_found`) and be unconsumed; `uploads.consume(upload_id, job_id)` (409/422 per repo error → map `invalid_input`).
   - `source_kind`: `upload` for uploads, else `classify_source_static(url)`.
   - dedup (docs/05 §1): `find_recent_done(source_url=… | sha256=upload.sha256, options=…)` unless `options.depth == "deep"` → `200`
     `{"job_id": <existing>, "status": "done", "deduplicated": true, "links": …}`.
   - else create job (`queued`), `queue.enqueue(job_id, "pipeline")` → `202 {"job_id", "status": "queued", "deduplicated": false, "links"}`.
     If enqueue fails → set the job `failed` (`dependency_down`) and return 503 `dependency_down`.
6. **`GET /v1/jobs`** (`status`, `limit`, `cursor`) → `{"items": [JobSummary], "next_cursor"}`; `JobSummary = {job_id, status, created_at, title, source_kind}`.
7. **`GET /v1/jobs/{id}`** → `JobStatus` exactly per docs/03 §2: stages list in `Stage` order (missing rows shown as `pending`), `progress`
   from the job row (default `{"pct": 0, "stage": null, "message": null}`), `links` built from `CARACAL_PUBLIC_BASE_URL`
   (`report`, `transcript`, `events`, `subtitles: {}` until subtitles exist). Invalid UUID path → 422; unknown → 404.
8. **`GET /v1/jobs/{id}/events`** — SSE (`text/event-stream`, `Cache-Control: no-cache`): **subscribe first, then send a snapshot** event
   (`event: status`, data = JobStatus) so nothing is missed between them; then forward channel events (`event: <type>`, `data: <json>`);
   comment keep-alive `: ping` every 15 s (injectable); when the job is terminal (snapshot already terminal, or an `end` event arrives) send
   `event: end` and close. Put the stream logic in a plain async generator function (`job_event_stream(...)`) and unit-test it directly with
   fakeredis — `httpx.ASGITransport` buffers whole responses, so over HTTP only test the terminal-job case (snapshot + end, then closed).
9. **`DELETE /v1/jobs/{id}`** — docs/03 §2 (updated): non-terminal → `set_cancel` + 202 `{"job_id","status":"cancelling"}`; terminal → delete
   job row (cascade) and `JobFiles(...).root` directory (only if it is inside `CARACAL_DATA_DIR/jobs/`) → 204. Unknown → 404.
10. **`GET /healthz`**: `{"ok", "version", "deps": {"postgres","redis","whisper","ollama"}}` each `"ok"|"down"`; checks run concurrently with a 2 s
    timeout each (postgres: a cheap repo/engine ping exposed via `AppDeps`; redis `PING`; whisper `GET {WHISPER_URL}/`; ollama
    `GET {OLLAMA_LOCAL_URL}/api/tags`); results cached 10 s (injectable clock); `ok` = postgres and redis both ok. Status code always 200.
11. **`cli serve`**: `uvicorn.run(create_app(settings), host=CARACAL_HOST, port=CARACAL_PORT, workers=1, log_config=None)` (our JSON logging),
    `proxy_headers=False`. Client IP for rate limiting = `request.client.host`.

## Accept
- Contract tests compare every response field name, status code and error code with docs/03 (not just "200 OK").
- auth: no header, wrong scheme, wrong token, token with a trailing space, `/healthz` without auth → each asserted.
- validation errors never contain the submitted value (test with a distinctive string in a bad field).
- 500 path: a route that raises a plain exception returns the envelope with "internal error" and no traceback text.
- jobs: url job → queued + enqueued in fakeredis stream under the prefix; upload job consumes the upload; second use of the upload rejected;
  dedup returns the existing id; `depth=deep` bypasses dedup; rate limit 429 + `Retry-After` on request N+1 with `CARACAL_RATE_LIMIT_PER_MIN=N`;
  enqueue failure → 503 and the job is `failed`.
- SSE: generator test — snapshot first, then a published stage event, then `end` closes the stream; event published **between** subscribe and
  snapshot is still delivered (inject a hook); terminal job over HTTP → snapshot + `end`.
- DELETE: running → 202 + cancel flag set; terminal → 204, rows and directory gone; directory outside data dir is never deleted.
- healthz: all-up, whisper down (MockTransport 500 / timeout), cache hit within 10 s, refresh after.
- gate green; no real network.
