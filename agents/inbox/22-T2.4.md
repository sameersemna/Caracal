## Requirements
1. **`report/model.py`** — pydantic v2 models for **every** type in docs/03 §5 (`Report`, `SpeakerIdentity`, `Claim`, `Verification`,
   `ReviewFlag`, `Answer`, sub-objects), field names and enums exactly as documented, `model_config = ConfigDict(extra="forbid")`,
   `schema_version: Literal["1.0"]`. Confidences `float` constrained to [0, 1]. Timestamps/durations floats in seconds. `evidence: list[str]`
   on every evidence-bearing item. Sections that a pipeline stage may not produce (e.g. verification when verify is skipped) default to empty lists.
   `Report.summary_view() -> ReportSummary` (docs/03 §3).
2. **`report/evidence.py`**
   - `EVIDENCE_ID_RE` — typed alternatives only: `seg:\d+`, `caption:\d+`, `web:\d+`, `hint:\d+`, `vp:S\d+`, `meta:[a-z][a-z0-9_]*`
     (so `"seg:2."` → `seg:2`, `"seg:2 S1"` → `seg:2`). `normalise_ids(values) -> list[str]` (flatten, dedupe, keep order).
   - `EvidenceItem(kind, ref, excerpt)` (excerpt ≤ 300 chars, whitespace-collapsed). `EvidenceIndex` with `add(...)`, `get(id)`, `__contains__`, and
     `build_evidence_index(*, transcript, platform_meta, probe_tags, hints, voiceprint_matches, caption_words, web_hits) -> EvidenceIndex`:
     `seg:<id>` (ref = `"{start:.1f}-{end:.1f}s {speaker}"`, excerpt = segment text), `meta:<field>` for title/description/channel/uploader/
     upload_date/tags/categories (+ `meta:tag_<key>` for probe tags), `hint:<n>`, `vp:<label>` (best match name + similarity), `caption:<n>` (one per
     caption cue-sized group of ~10 words, ref = time range), `web:<n>` (url, title/snippet excerpt). Any argument may be empty/None.
   - `validate_citations(report, index) -> tuple[Report, int]`: walk the report **generically** (pydantic introspection — do not hard-code each
     section): normalise each `evidence` list, drop ids not in the index; an item inside a **list** whose evidence becomes empty is removed and
     counted; a **singular** evidence-bearing object (summary, context) with empty evidence is kept but its `confidence` (if any) set to 0 and a
     `ReviewFlag(severity="warn", field=<path>, message="uncited")` appended to `quality.review_flags`; `Verification.sources[*].evidence_id`
     must resolve too (unresolved source dropped; a non-`unverified` verdict left with no source becomes `unverified`, docs/04 §8);
     `SpeakerIdentity.candidates` follow the list rule. Then set `report.evidence_index` to exactly the cited ids, set
     `quality.dropped_uncited`, and return. Idempotent (running twice changes nothing more).
3. **`report/render_md.py`** — `render_markdown(report) -> str`: H1 title; source/audio table; languages; speakers (name or "unidentified",
   confidence, role, candidates with sources); summary; context; chapters with `mm:ss` (`h:mm:ss` > 1 h); topics; entities grouped by type; key
   quotes as blockquotes with speaker + time; claims with their verification verdicts; translations; quality + review flags; evidence appendix
   (`[seg:12] 03:14.2–03:18.0 S2 — excerpt`). **Untrusted text is escaped** (S9): every string from transcript/metadata/web/LLM passes through
   `md_escape` (escape `\ * _ ` [ ] < > # | !` and backticks, strip ASCII control chars except `\n`, collapse newlines inside table cells) —
   rendered Markdown must contain no raw HTML and no link/image syntax originating from content.
