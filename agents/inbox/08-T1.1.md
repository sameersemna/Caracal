## Requirements

### ssrf.py (S3)
- `Resolver` protocol: `async def resolve(host: str, port: int) -> list[str]` (IP strings). Default impl uses `loop.getaddrinfo(host, port, type=SOCK_STREAM)`.
- `IpPolicy` = `Callable[[ipaddress.IPv4Address | IPv6Address], bool]` (True = allowed). `default_ip_policy(ip)`: unwrap IPv4-mapped IPv6
  (`::ffff:a.b.c.d`) and 6to4/NAT64 (`64:ff9b::/96`) to the embedded IPv4 first; then allowed **only if** `ip.is_global` and not
  multicast/reserved/unspecified/loopback/link-local/private. (So `0.0.0.0`, `127.x`, `10.x`, `172.16/12`, `192.168/16`, `169.254.x`,
  `100.64/10` CGNAT, `::1`, `fc00::/7`, `fe80::/10` are all rejected.)
- `async def resolve_and_check(url: str, *, resolver, policy=default_ip_policy) -> PinnedTarget(scheme, host, port, ip)`:
  scheme must be http/https; host required; **IP-literal hosts** (incl. decimal `2130706433`, octal `0177.0.0.1`, hex `0x7f.1`) are parsed
  with `ipaddress` after normalising via `socket.inet_aton` semantics where applicable and checked by policy; userinfo (`user:pass@`) →
  `source_blocked`; **every** resolved address must pass the policy (any failing → `source_blocked`), pin the first. Errors:
  `CaracalError(source_blocked, …)`; DNS failure → `source_unavailable`. Never include the full URL query in error messages (host only).

### direct.py — `async def download_direct(url, dest: Path, *, resolver, policy=default_ip_policy, max_bytes, timeout_s=60, max_redirects=5) -> DirectInfo`
- **Pinned connection:** a `PinnedBackend(httpcore.AsyncNetworkBackend)` wrapping `httpcore.AnyIOBackend()` whose
  `connect_tcp(host, port, timeout=None, local_address=None, socket_options=None)` connects to the pinned IP instead of `host` when `host`
  equals the pinned hostname (anything else → raise). TLS keeps SNI + certificate verification for the original hostname (httpcore passes
  `server_hostname=<origin host>` to `start_tls` — judge-verified in httpcore 1.0.9 `_async/connection.py`). Build the client per hop:
  `httpx.AsyncHTTPTransport()` then replace its `_pool` with `httpcore.AsyncConnectionPool(network_backend=PinnedBackend(...), ssl_context=…)`
  (httpx 0.28 has no public `network_backend` argument — add a comment and a test that fails if the private attribute disappears).
- `follow_redirects=False`; handle 301/302/303/307/308 manually: resolve `Location` relative to the current URL, **re-run `resolve_and_check`**
  for every hop; > `max_redirects` → `source_unavailable`.
- Status ≠ 200 → `source_unavailable` (include status). `Content-Type` must start with `audio/`, `video/`, or be `application/octet-stream`
  / `application/ogg` → else `unsupported_media`. `Content-Length` > max → `too_large` before reading; streamed byte count > max → abort,
  delete the partial file, `too_large`. Write to `dest.with_suffix(dest.suffix + ".part")`, compute sha256 while streaming, `os.replace` at the end.
- `DirectInfo(final_url, content_type, size_bytes, sha256, filename)` — filename from `Content-Disposition` or the URL path, sanitised (S6).

### upload.py (S6) — `async def save_upload(chunks: AsyncIterator[bytes], filename: str, files: UploadFiles, *, max_bytes) -> UploadInfo`
- Sanitise: basename only, keep `[A-Za-z0-9._-]`, collapse others to `_`, strip leading dots, ≤ 100 chars, empty → `upload.bin`.
- Stream to `.part`, sha256 on the fly, cap → `too_large` (partial deleted), atomic rename. `UploadInfo(upload_id, filename, size_bytes, sha256, path)`.

### `POST /v1/uploads` (docs/03 §2)
- Register `("POST", "/v1/uploads")` in `body_limits` with `CARACAL_MAX_UPLOAD_MB * 1024 * 1024` (+ 64 KiB multipart overhead).
- Parse the multipart body **streaming** from `request.stream()` with `python_multipart.multipart.MultipartParser(boundary, callbacks)`
  (signature: `MultipartParser(boundary, callbacks={}, max_size=inf, *, max_header_count=8, max_header_size=4224)`), feeding file-part bytes
  into `save_upload` — never `await request.form()` / `request.body()` (they spool or buffer whole files). Exactly one part named `file`
  with a filename; other fields ignored; zero or two file parts → 422 `invalid_input`. Non-multipart content type → 415 `unsupported_media`.
- `UploadRepo.create(...)` → `201 {"upload_id","filename","size_bytes","sha256"}`. Disk write failure → 500 `internal` (no path in message).

### router.py — add `async def classify_source(url, *, resolver, policy, http_head) -> Literal["direct","platform"]`
- Known platform hosts (suffix match: `youtube.com`, `youtu.be`, `vimeo.com`, `soundcloud.com`, `tiktok.com`, `instagram.com`,
  `facebook.com`, `fb.watch`, `x.com`, `twitter.com`, `twitch.tv`, `dailymotion.com`, `bilibili.com`, `rumble.com`) → `platform` (no network).
- Static media extension → `direct` (existing `classify_source_static`). Otherwise one pinned `HEAD` (via the same SSRF path, 10 s,
  no redirects followed beyond 5): `audio/*|video/*` → `direct`, else `platform`. HEAD failure → `platform`.
