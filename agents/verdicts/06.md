## Attacks — defects
- **A1 pre-auth body read (DoS).** FastAPI parses the `JobCreate` body *before* the router-level auth dependency runs. A request with
  **no Authorization header** and `Transfer-Encoding: chunked` made the server read **30 MiB** and answer 422 with validation details
  (an authenticated client: 50 MiB). The 64 KiB cap only works when `Content-Length` is declared. Unauthenticated clients must get 401
  before any body byte is read, and no request may make the server buffer more than the cap.
- **A2 `rate_limited`** is emitted as a literal envelope; `ErrorCode` lacks it (docs/03 §4).

## Required fixes
1. **Pure ASGI middleware** (in `app.py`, outermost after error handling) for every path starting with `/v1/`: check the bearer token
   (same rules as `require_auth`, constant-time) **before calling the app**; on failure send the 401 envelope + `WWW-Authenticate` without
   reading the body. Keep `require_auth` on the router as defence in depth.
2. **Streaming body cap** in the same ASGI layer: wrap `receive`, count `http.request` body bytes, and when the running total exceeds the
   per-route limit, stop reading and respond 413 `too_large` immediately (works with and without `Content-Length`, chunked included).
   Limits: `POST /v1/jobs` and every other JSON `/v1` route 64 KiB; a `body_limits` mapping so T1.1 can register `POST /v1/uploads` with its own cap.
   Remove the now-redundant route-level `len(body)` check only if the middleware covers it (tests prove it).
3. Add `ErrorCode.RATE_LIMITED = "rate_limited"` → 429 in `errors.py`; update `tests/unit/test_errors.py`'s expected set accordingly
   (allowed; declare it). The route raises `CaracalError(RATE_LIMITED, details={"retry_after_s": n})`; the handler sets `Retry-After`.
4. Tests (contract, ASGI-level so no real socket is needed — drive the app with a hand-written ASGI `receive` that yields many chunks and
   **counts how many chunks were pulled**): unauthenticated chunked POST → 401 and ≤ 1 chunk pulled; authenticated oversize chunked
   → 413 and pulled bytes ≤ limit + one chunk; unauthenticated invalid JSON → 401 (not 422); rate-limited response uses the `ErrorCode`.
